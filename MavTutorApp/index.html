Run MavTutor in your browser

MavTutor uses the Java classes from the CSE 1325 project with a small HTML and CSS interface. GitHub Pages serves this guide; the Java application runs on your computer.

Start on Windows

  1. Install a JDK and Apache Ant.
  2. Download the project ZIP and extract it.
  3. Open the extracted P10 folder and double-click run-web.bat.
  4. Open http://127.0.0.1:8080 in your browser.

Start on macOS or Linux

Install a JDK and Apache Ant, download the project, open a terminal in P10, and run:

ant compile
java --add-modules jdk.httpserver -cp target web.MavTutorWeb

Then open http://127.0.0.1:8080.

What the app manages

Courses, students, tutors, scheduled sessions, and 1–5 star reviews. Data is saved on your computer. Tutor SSNs are not requested or stored.
